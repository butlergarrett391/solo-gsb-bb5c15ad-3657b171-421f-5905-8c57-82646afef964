# 骑马钉小册子 PDF 拼版（Booklet Imposer）

面向小型印刷店的小册子拼版 Web 应用。上传 PDF 后按**骑马钉（saddle stitch）**
规则重排为「每张纸 4 页」的版面，界面展示每张纸正反面的页码预览，
并可下载保持**原页面尺寸**的拼版 PDF。

技术栈：Node.js + Express + 原生 HTML/CSS/JavaScript + [pdf-lib](https://pdf-lib.js.org/)。

## 一键启动

确保已安装 Docker 与 Docker Compose（Docker Desktop 自带），在项目目录执行：

```bash
docker compose up -d --build
```

依赖会在**镜像构建阶段自动安装完成**，容器启动即可使用，无需手动 `npm install`。

启动后访问：

> **http://localhost:8080**

停止服务：

```bash
docker compose down
```

## 拼版规则

- 每张纸正反面共放置 **4 个原页面**；
- 页数不足 4 的倍数时，**在文末自动补空白页**；
- 第 1 张纸正面（从左到右）：**末页 | 首页**；背面：**第二页 | 倒数第二页**；
- 其余纸张逐层向内递进。例如 12 页（3 张纸）：

  | 纸张 | 正面（左｜右） | 背面（左｜右） |
  |---|---|---|
  | 第 1 张 | 12 ｜ 1 | 2 ｜ 11 |
  | 第 2 张 | 10 ｜ 3 | 4 ｜ 9 |
  | 第 3 张 | 8 ｜ 5 | 6 ｜ 7 |

- **保持原页面尺寸**：每张纸宽度 = 左右两页宽度之和，高度取两页较高者；
  原页面以 100% 比例嵌入，不缩放、不旋转。A4 竖版输入时，输出纸张为
  A3 横版（595.28 × 420.94 pt）。
- 补齐的空白页尺寸以原 PDF 首页为准。

## 打印与装订

1. 用输出的拼版 PDF 双面打印，翻转方式选择 **短边翻转（Flip on short edge）**；
2. 全部纸张按输出顺序叠放，沿中线对折；
3. 折好的书帖中缝套叠，骑缝订两个订书钉，即成骑马钉小册子。

> 可选：上传前勾选「在每张纸折叠中线添加浅灰参考线」，便于对折定位
> （正式印刷时不勾选即可）。

## 配置项

通过 `docker-compose.yml` 的 `environment` 调整（均有默认值，不改也能用）：

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `MAX_UPLOAD_MB` | `50` | 单个 PDF 上传大小上限（MB） |
| `JOB_TTL_MINUTES` | `30` | 拼版结果在服务端内存中保留的分钟数，过期自动清理 |
| `MAX_JOBS` | `20` | 服务端最多缓存的任务数，超出后最早的任务被淘汰 |
| `HOST_PORT`（compose 变量） | `8080` | 宿主机访问端口，如 `HOST_PORT=9000 docker compose up -d --build` |

容器内服务固定监听 **3000** 端口，由 Compose 映射到宿主机。
任务只保存在内存中（不落盘），容器重启即清空。

## 本地开发（不使用 Docker）

要求 Node.js ≥ 18。

```bash
npm install
npm start
```

然后访问 http://localhost:3000 。同样支持上述环境变量，例如：

```bash
PORT=3000 MAX_UPLOAD_MB=100 npm start
```

```
.
├── server.js            # Express 服务：上传 / 拼版 / 下载 / 任务缓存
├── lib/
│   └── impose.js        # 骑马钉拼版核心逻辑（pdf-lib）
├── public/
│   ├── index.html       # 上传与纸张正反面预览界面
│   ├── styles.css
│   └── app.js
├── Dockerfile           # 多依赖构建期安装，启动即用

└── package.json
```

## 说明与限制

- 适合常规竖版、无旋转标记的 PDF；页面含 `/Rotate` 旋转标记时按原始坐标拼版，
  建议先用排版软件导出为正向页面。
- 已加密（带打开密码）的 PDF 需先解除密码再上传。
- 拼版结果仅暂存内存（默认 30 分钟），请及时下载；本应用面向店内网络使用，
  未内置账号鉴权，不要直接暴露到公网。
